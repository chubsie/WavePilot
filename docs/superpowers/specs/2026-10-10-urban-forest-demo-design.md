# WavePilot 폐허 시가전·국경 산악전 시연 UI 설계

## 목표

브라우저에서 실시간 3D 드론 시야를 조종하면서, 같은 화면에서 YOLO 탐지 결과와 Nemotron 상황 보고서를 확인하는 시연 환경을 만든다. 시연자는 장갑 IMU를 기본 입력으로 사용하고, 개발 중에는 키보드·마우스를 사용한다. 수동 조종이 어렵거나 입력이 끊기면 자동 비행 경로로 즉시 전환할 수 있어야 한다. 드론은 주요 벽·건물·벙커·절벽과 지면을 통과하지 않는다.

시연은 두 환경을 제공한다.

- 도심전: 건물, 골목, 교차로, 정차 차량, 이동 인원
- 국경 산악전: 계곡, 암벽, 능선, 군용도로, 벙커, 엄폐된 인원, 이동 차량

## 범위

이번 구현에 포함한다.

- 폐허 시가전·국경 산악전 실시간 3D 장면
- 드론 1인칭 카메라와 수동 비행
- 키보드·마우스 입력, 장갑 IMU 입력 어댑터, 자동 비행 전환
- 화면 위 YOLO 스타일 탐지 박스와 트랙 ID
- 실시간 탐지 목록과 이벤트 기반 Nemotron 보고서 UI
- Orin Nano 연결 상태와 로컬 데모 폴백
- 시나리오 전환과 초기 위치 재설정

이번 구현에서는 실제 기체 제어, 교전 판단, 표적 지정, 다중 드론, 실제 IMU 펌웨어 변경을 다루지 않는다. 충돌은 시연용 구체/AABB 근사이며 강체 물리 시뮬레이션은 아니다.

## 실행 구조

### Lenovo 노트북

- 브라우저에서 3D 환경과 UI를 렌더링한다.
- Web Serial 또는 Nordic UART Service BLE로 장갑 IMU 데이터를 수신한다.
- 키보드·마우스 입력과 자동 비행을 지원한다.
- Orin Nano에서 전달받은 탐지·보고 데이터를 표시한다.
- Orin 연결이 없으면 동일한 메시지 계약을 따르는 로컬 데모 데이터로 전환한다.

### Jetson Orin Nano

- YOLO11n으로 카메라 프레임을 탐지하고 트랙 ID를 유지한다.
- Nemotron-3-Nano-4B를 llama-server로 제공한다.
- 현재 저장소의 state, decision, report 메시지 형식을 그대로 사용한다.

3D 시뮬레이션이 생성하는 카메라 영상은 초기 버전에서 브라우저 안에서 탐지 결과와 함께 합성한다. 실제 Orin 영상 입력이 준비되면 카메라 프레임 공급자만 교체한다.

## 화면 구성

화면은 55:45 비율의 단일 관제 화면이다.

### 상단 상태 바

- WavePilot 로고와 현재 시나리오
- `시가전` / `산악전` 전환
- 비행 모드: `IMU`, `KEYBOARD`, `AUTO`
- Orin, YOLO, Nemotron 연결 상태
- 시뮬레이션 재설정

### 좌측 55%: 드론 시야

- 드론 1인칭 실시간 3D 카메라
- 대상 탐지 박스, `T-03` 형식의 트랙 ID, 신뢰도
- 고도, 속도, 방향, 배터리, 카메라 상태 HUD
- IMU 미연결 시 키보드 도움말
- 자동 비행 중 경로 상태와 수동 복귀 안내

### 우측 45%: 분석

상단의 `LIVE DETECTION`과 하단의 `SITUATION REPORT`로 나눈다.

`LIVE DETECTION`은 YOLO 결과를 즉시 표시한다.

- 트랙 ID
- 객체 종류
- 신뢰도
- 화면 또는 시나리오 기준 위치
- 이동 상태

`SITUATION REPORT`는 Nemotron이 사건 발생 시 작성한다.

- 생성 시각과 사용한 상태 시각
- 관측 문장
- 대상 간 관계 문장
- 추가 관측 권고
- 각 문장의 근거 트랙 ID
- grounded/flagged 상태
- `다시 분석` 버튼

## 시각 언어

선택된 관제 UI 방향은 `Field Command`다. 3D 장면은 저폴리 스타일을 사용하지 않고 영화적 실사를 목표로 한다. `R-Point`의 습하고 폐쇄적인 열대 정글과 `The Pianist`의 차갑고 황폐한 전시 유럽 시가지를 분위기 참고 자료로 사용하되, 특정 세트나 장면을 복제하지 않고 독자적인 공간으로 구성한다.

- 저채도 흑녹색 배경
- 형광 라임을 연결·탐지·정상 상태 강조색으로 사용
- 황색은 주의, 적색은 연결 실패와 위험 상태에만 사용
- 모노스페이스 계열의 계측 정보와 좁은 산세리프 제목을 조합
- 얇은 선, 작은 상태 라벨, 제한된 그림자로 실제 계측 장비처럼 표현
- 시가전은 차가운 회색·탈색된 석조색·먼지색, 산악전은 젖은 암석색·올리브색·청회색 안개를 장면 보조색으로 사용
- 드론 화면에 약한 필름 그레인, 비네팅, 렌즈 오염, 거리 연무를 적용하되 탐지 박스의 판독성을 해치지 않는다

## 3D 장면

### 공통 원칙

- `CINEMATIC` 모드는 실사 PBR 재질, 고밀도 식생·잔해, 동적 그림자, 안개와 후처리를 사용한다.
- `PERFORMANCE` 모드는 식생·잔해 밀도, 그림자 거리, 렌더 해상도와 후처리를 낮춘다.
- 1080p Lenovo 브라우저에서 `CINEMATIC` 30 FPS를 목표로 하고 미달 시 `PERFORMANCE`로 즉시 전환할 수 있게 한다.
- 가까운 핵심 자산은 중간 해상도 메시와 1K PBR 텍스처를 사용하고, 반복 자산은 인스턴싱한다.
- 먼 오브젝트는 단순화된 메시와 안개로 감춰 GPU 비용을 제한한다.
- 장면은 시연 동선을 기준으로 구성하며 무제한 자유 비행 지도는 만들지 않는다.
- Blender MCP로 지형·건물·식생·잔해를 배치하고 GLB로 내보낸다.
- PBR 에셋 공급자가 비활성일 때는 Blender 절차형 메시와 베이크 가능한 이미지 텍스처를 사용한다.
- GLB 로드에 실패할 때만 기존 Three.js 절차형 폴백을 사용하고, 정상 시연에서는 Blender 자산을 우선한다.

### 시가전

- 1930~40년대 유럽 구도심을 연상시키는 석조·벽돌 파사드로 긴 주도로와 좁은 골목을 만든다.
- 건물은 온전한 박스가 아니라 무너진 외벽, 노출된 내부 바닥, 깨진 창, 그을음, 탄흔을 갖는다.
- 도로에는 벽돌 더미, 목재 들보, 뒤틀린 금속, 모래주머니, 파손된 가로등과 불탄 차량을 배치한다.
- 젖은 자갈·석재 도로가 흐린 하늘을 약하게 반사하도록 한다.
- 차가운 흐린 하늘, 낮은 채도, 먼지와 연무로 긴 거리의 깊이와 고립감을 만든다.
- 정차 차량 1대, 이동 차량 1대, 보행자 2명을 탐지 대상으로 유지한다.
- 핵심 사건: 폐허 골목의 보행자와 주도로 차량의 이동 경로가 가까워짐

### 국경 산악전

- 깊은 계곡, 급경사 암벽, 좁은 능선과 굽은 군용도로를 만든다.
- 콘크리트 벙커, 감시초소, 철조망, 모래주머니와 폐쇄된 터널 입구를 랜드마크로 둔다.
- 차가운 흐린 하늘, 능선 사이의 낮은 안개, 젖은 바위·흙 PBR 재질을 사용한다.
- 식생은 실제 모델 기반의 드문 소나무와 낮은 관목만 사용해 암벽과 고도감이 주인공이 되게 한다.
- 인원 T-11은 벙커 주변 능선을 이동하고 차량 T-12는 군용도로를 따라 벙커 방향으로 접근한다.
- AUTO 경로는 계곡 진입 → 도로 추적 → 능선 초소 확인 → 벙커 상공 통과 순서다.
- 핵심 사건: 차량이 벙커에 접근하는 동안 인원이 감시 사각지대로 이동

## 조종

입력은 동일한 정규화 명령으로 변환한다.

```text
FlightInput { roll, pitch, yaw, throttle, source, timestamp }
```

- `IMU`: `main`의 최신 `G,<seq>,<roll>,<pitch>,<yaw_rate>,<flex0>,<flex1>,<buttons>` 형식을 사용한다. USB Web Serial과 Nordic UART Service BLE를 모두 지원한다.
- flex0는 저장된 flat/bent 보정을 거쳐 throttle 0..1로 변환한다. 엄지 버튼(bit 1)은 수동/AUTO 전환, 중지 버튼(bit 0)은 보조 액션으로 전달한다.
- `KEYBOARD`: WASD 이동, QE 회전, RF 상승·하강을 기본값으로 한다.
- `AUTO`: 시나리오별 웨이포인트를 따라 이동하고 관심 지점을 바라본다.

입력 우선순위는 사용자가 선택한 현재 모드가 결정한다. IMU 데이터가 일정 시간 들어오지 않으면 드론은 제자리 정지하고 UI에 연결 손실을 표시한다. 자동 모드로의 전환은 명시적인 버튼 조작으로만 수행한다. 자동 모드에서도 키보드 입력이 들어오면 즉시 수동으로 복귀할 수 있다.

## 충돌

- 드론은 반지름 0.7m의 구체 collider를 사용한다.
- Blender GLB의 `COLLIDER_` 프록시와 시가전의 주요 `Ruin_` 외벽에서 AABB 충돌 영역을 만든다.
- 이동이 충돌하면 가능한 축 방향으로 미끄러지며, 불가능하면 정지한다.
- 충돌 시 HUD에 `OBSTACLE / FLIGHT BLOCKED`를 표시한다.
- 작은 식생·벽돌·유리 조각은 충돌 대상에서 제외한다.

## 탐지와 보고 데이터 흐름

1. 3D 카메라가 장면을 렌더링한다.
2. YOLO 또는 로컬 데모 탐지기가 대상과 트랙 ID를 보낸다.
3. 탐지 박스와 `LIVE DETECTION`이 즉시 갱신된다.
4. 트랙 집계기가 짧은 오탐을 제거하고 현재 상태를 만든다.
5. 새로운 안정 트랙, 위험 구역 진입, 거리·방향의 의미 있는 변화가 보고 이벤트를 발생시킨다.
6. 규칙 기반 decision은 즉시 갱신한다.
7. Nemotron 보고서는 단일 백그라운드 작업으로 생성한다.
8. 보고가 완료되면 기존 보고서를 원자적으로 교체한다.

Nemotron 요청에는 최소 8초의 쿨다운을 적용한다. 이전 요청이 실행 중이면 요청을 무한히 쌓지 않고 최신 상태 하나만 보류한다. `다시 분석`은 같은 제한 안에서 현재 상태의 새 보고서를 요청한다.

## 보고서 규칙

보고서는 한국어로 표시하고 문장마다 근거 트랙 ID를 유지한다.

```text
[T-03] 동측 골목에서 보행자 한 명이 북쪽으로 이동 중입니다.
[T-07] 차량 한 대가 교차로에 정차해 있습니다.
[T-03,T-07] 두 대상의 이동 경로가 가까워 추가 관측이 필요합니다.
```

LLM은 비행 명령, 적대성 판정, 피아 식별, 교전·표적 결정을 생성하지 않는다. 관측 사실, 대상 간 관계, 추가 관측 제안만 작성한다.

## 오류와 폴백

- Orin 연결 실패: 상태 바를 적색으로 표시하고 로컬 데모 모드로 전환한다.
- YOLO 실패: 마지막 탐지를 일정 시간 유지한 뒤 stale 표시와 함께 제거한다.
- Nemotron 지연: 기존 보고서를 유지하고 `분석 중` 상태를 표시한다.
- Nemotron 실패: 기존 보고서를 유지하고 오류 종류와 재시도 버튼을 표시한다.
- IMU 연결 실패: 제자리 정지하고 키보드 전환을 안내한다.
- WebGL 성능 저하: 그림자, 안개, 식생 밀도를 낮추는 성능 모드를 제공한다.

## 구현 경계

3D 장면, 입력, 데이터 소스, UI를 독립 모듈로 둔다.

- `scene`: 시가·산악 장면과 충돌 영역 수명주기
- `flight`: 드론 운동과 카메라
- `input`: IMU, 키보드, 자동 경로 어댑터
- `detection`: 실제/데모 탐지 소스와 오버레이
- `report`: state/report 스트림과 표시 상태
- `ui`: 상태 바, 탐지 목록, 보고서, 제어 버튼

실제 YOLO·Nemotron 연결과 로컬 데모는 같은 메시지 계약을 사용해 UI가 데이터 출처를 알 필요가 없게 한다.

## 검증

- 시가전·산악전 전환 후 장면과 추적 상태가 올바르게 초기화된다.
- 키보드 수동 조종, IMU 파서, 자동 경로 및 수동 복귀를 각각 검증한다.
- 새 트랙과 위험 이벤트가 보고를 발생시키며, 일반 프레임은 LLM 요청을 발생시키지 않는다.
- 보고 생성 중에도 비행과 YOLO 오버레이가 끊기지 않는다.
- 모든 보고 문장이 유효한 트랙 ID를 인용한다.
- Orin, YOLO, Nemotron, IMU 연결 실패별 폴백 상태를 검증한다.
- Lenovo 브라우저에서 목표 30 FPS를 기준으로 검증하고, 미달 시 성능 모드가 적용되는지 확인한다.
- 시가전에서 무너진 파사드·잔해·연무가, 산악전에서 계곡·암벽·벙커·군용도로가 실제 GLB 자산으로 렌더링되는지 시각 검증한다.
- 벽·벙커·절벽을 향해 비행할 때 통과하지 않고 정지 또는 표면 이동하는지 검증한다.
- USB와 BLE가 같은 장갑 라인을 파싱하고 flex throttle·버튼 모드 전환이 동작하는지 검증한다.
- 동일 구도에서 `CINEMATIC`과 `PERFORMANCE` 전환 시 핵심 탐지 대상과 조종 기능이 유지되는지 확인한다.

## 완료 기준

- 한 브라우저 화면에서 두 시나리오를 전환할 수 있다.
- 좌측 3D 화면을 키보드로 수동 조종하고 자동 모드로 전환할 수 있다.
- IMU 연결 지점이 기존 직렬 형식과 호환된다.
