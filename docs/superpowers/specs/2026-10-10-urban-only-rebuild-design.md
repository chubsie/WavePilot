# WavePilot 폐허 시가전 단일 시나리오 재구축 설계

## 범위

산악전과 시나리오 선택 UI를 제거하고 폐허 시가전 하나만 제공한다. 기존 Field Command UI, YOLO 탐지, Nemotron 보고서, 키보드·AUTO·장갑 조종을 유지한다.

## Blender 장면

- 직선 주도로와 건물 사이의 측면 통로를 중심으로 유럽식 건물 12동을 배치한다.
- 건물은 도로 바깥에 완전한 외벽 셸로 두고, 창문·문·처마·발코니·상점 셔터를 입체 메시로 만든다.
- 일부 외벽과 지붕만 파괴하고, 카메라가 끼는 대형 내부 박스나 도로 위 돌출 바닥은 만들지 않는다.
- 벽돌 더미, 파손 차량, 모래주머니, 가로등은 도로 가장자리에 배치해 중앙 9m 폭을 항상 비워 둔다.
- PBR 벽돌·석재·젖은 도로·금속 재질과 흐린 조명·먼지 연무를 사용한다.
- `T-03` 보행자와 `T-07` 차량은 열린 도로와 광장에 배치한다.

## 충돌

- 렌더 메시 이름으로 충돌을 추측하지 않는다.
- Blender의 `COLLIDER_Building_*`, `COLLIDER_Barricade_*` 프록시만 충돌 영역으로 사용하고 화면에서는 숨긴다.
- 시작 위치, AUTO 경로, 탐지 대상 주변 14m 관측 위치가 모든 프록시 밖인지 자동 검증한다.
- 빠른 이동은 substep으로 처리해 벽을 관통하지 않으며, 접촉 후 후진과 벽면 이동이 가능하다.

## 장갑과 비행 물리

- `USB 연결`과 `Bluetooth 연결`은 클릭 이벤트 안에서 각각 Web Serial/Web Bluetooth 기기 선택창을 직접 연다.
- 연결·취소·오류 상태를 화면 상단에 표시한다.
- `main`과 같은 확장 장갑 라인, flex 보정, 버튼 모드 전환을 사용한다.
- IMU 비행은 추력 방향, 2G 최대 추력, 중력 9.81m/s², 수평·수직 항력으로 속도를 적분한다.
- 키보드와 AUTO도 목표 속도 순간 변경 대신 가속과 항력으로 이동한다.

## AUTO 관측

- 1초 이상 안정적으로 보이고 신뢰도 70 이상인 가장 가까운 대상을 선택한다.
- 대상 방향으로 회전한 뒤 접근하며 약 14m에서 정지하고 관측한다.
- 시야가 차단되거나 충돌하면 접근을 중단한다. 대상을 2초 이상 놓치면 순찰로 복귀한다.

## 검증

- 도로 시작점과 AUTO 순찰·접근 경로가 충돌체 밖인지 실제 GLB 기준으로 계산한다.
- 벽 관통 방지, 후진 가능, 목표 거리 유지, 대상 소실 정지를 Node 테스트로 검증한다.
- USB와 BLE 연결 호출이 클릭 시 직접 발생하는지 검증한다.
- Chrome에서 장면 로딩, AUTO, UI, 브라우저 오류를 확인한다.
